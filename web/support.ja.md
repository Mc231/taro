# Taro サポート

## お問い合わせ

volodymyr.shyrochuk@gmail.com までご連絡ください。設定 → ヘルプとよくある質問 に表示されるサポートIDを添えていただくと、個人情報なしで購入やリーディングを確認できます。設定 → ヘルプとよくある質問 → サポートにメールする から直接送ることもできます。

## 危機対応サービスではありません

Taroは危機対応や緊急のためのサービスではありません。リーディングは医療・法律・金融・心理の専門的な助言ではありません。危険な状況にある場合や、自分を傷つけることを考えている場合は、今すぐお住まいの地域の緊急番号に電話してください。アプリの 設定 → 相談窓口 で、話を聞いてくれる窓口を確認できます。

## よくある質問

- **リーディングで未来がわかりますか？** いいえ。Taroはタロットの象徴を、ふり返りのきっかけとエンターテインメントとして使います。
- **アカウントは必要ですか？** いいえ。登録なしで使えます。
- **AIリーディングの仕組みは？** 最初のAIリーディングの前に、何が送信されるかを説明し、許可を求めます。設定 → AIリーディング でオフにでき、クラシックなリーディングはそのまま使えます。
- **日記はどこにありますか？** 端末と端末のバックアップの中です。移行するには 設定 → バックアップを書き出す と 設定 → バックアップを読み込む を使います。
- **別の端末でリーディングを購入しました。** リーディングのクレジットはインストールごとに管理されます。設定 → 別のデバイスからリーディングを移行 を開き、表示される移行コードをサポートIDと一緒にメールで送ってください。
- **「バナー広告を削除」を復元するには？** 設定 → リーディングを追加する → 購入を復元。
- **返金はできますか？** 返金は購入したストアが、そのストアのポリシーに従って対応します。
- **広告とプライバシーの選択を変えるには？** 設定 → プライバシーの選択。

そのほかの回答はアプリの 設定 → ヘルプとよくある質問 にあります。

## データを削除する

1. 設定 → すべてのデータを削除 を開きます。
2. 削除されるものと残るものを確認します。あとで日記が必要になるかもしれない場合は、先にバックアップを書き出してください。
3. 確認のため「削除」と入力し、「すべてのデータを削除」をタップします。

この端末の日記、メモ、設定が削除され、サーバーにもリーディング、報告、利用履歴の削除を依頼します。残っているリーディングのクレジットと「バナー広告を削除」は購入済みのため保持されます。メールで依頼する場合はサポートIDを添えてください。詳細：[プライバシーポリシー](privacy.ja.html) · [利用規約](terms.ja.html)
