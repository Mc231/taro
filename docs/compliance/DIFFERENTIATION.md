# Differentiation evidence (4.3(b), PR2)

Phase 19.1. Apple 4.3(b) asks for a "unique, high-quality experience" in a saturated category, and Play's repetitive-content policy asks the same. This file maps each row of [01 §4.1](../specs/01_PRODUCT.md#41-differentiation-vs-typical-category-apps-43-evidence) to the screen that ships it and a screenshot. It feeds the App Review notes ([`REVIEW_NOTES.md`](REVIEW_NOTES.md), submitted in Phase 20) and the store copy.

**Screenshots:** until the Phase 20 store screenshots exist (`apps/taro/integration_test/screenshots/`, 05 §9.4), each row links the reference golden PNG of the real screen (`apps/taro/test/golden/goldens/`, rendered by the shipped widgets with the final `codex_v1` art). When the store set is captured, add its file next to the golden.

Last checked: 2026-10-02 (links point at the golden files in the working tree on that date; `melos run test:golden` keeps them current).
